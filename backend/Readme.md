# Shop Management MERN

MERN application for a cosmetics and general store.

## Backend

Node.js + Express.js + MongoDB

## Main Features

- Admin authentication
- Customer authentication with CAPTCHA
- Product CRUD
- Category and subcategory filtering
- Product search
- Sorting and pagination
- Cloudinary image upload
- Multiple product images
- Related products
- Customer visit tracking
- Product analytics
- Admin dashboard analytics
- Protected product details

## Run Backend


cd backend
npm install
npm run dev
